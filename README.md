# README.md для проекта:

```markdown
# 🤠 Тяни ковбоя! — интерактивная резиновая кукла

Одностраничная браузерная игра на **Babylon.js**: растягиваемый человечек-ковбой,
у которого можно тянуть конечности. Перетянешь — часть с треском оторвётся,
улетит, а потом её можно пришить обратно. Никакой сборки, никаких ассетов —
один HTML-файл, вся геометрия и текстуры генерируются кодом.

---

## 🎮 Геймплей

Главный герой — «резиновый Джо», полный ковбой: клетчатая рубашка, жилетка
с бахромой, деним, сапоги со шпорами, шляпа и платок. На заднем плане —
лагерь: второй ковбой в шляпе и трусах в горошек греет руки у костра,
рядом срубленное дерево и раскрытая палатка. Оба живые: дышат, моргают,
следят взглядом.

| Действие | Как |
|---|---|
| **Тянуть конечность** | ЛКМ (или палец) по кисти / сапогу / голове → вести мышь |
| **Отрыв** | довести полоску натяжения до красной зоны |
| **Перенос оторванного** | схватить деталь снова и нести за собой |
| **Бросок** | отпустить деталь на быстром движении — ей передаётся скорость |
| **Пришить обратно** | поднести деталь к ране на теле (сработает «магнит») |
| **Вращение камеры** | тянуть пустое место (после первого рывка — ЛКМ по фону) |
| **Зум** | колесо мыши / щипок |
| **Кнопки** | «Пришить всё» — вернуть все части; «Сначала» — полный сброс; 🔊 — звук |

### Механики

- **Растяжение** — пружинная физика: конечность тянется за курсором,
  утолщается/сужается по закону сохранения объёма, локоть/колено
  распрямляются по мере натяжения.
- **Отказ от перетягивания** — отпустил раньше порога: недодемпфированная
  пружина возвращает конечность с «боянгом», изгибы возвращаются.
- **Отрыв** — по достижении порога: скрип достигает пика, разрыв,
  облачко пуха из раны, тряска камеры, лицо в шоке (брови вверх, рот «О»),
  деталь улетает с физикой (гравитация, вращение, отскоки от земли).
- **Раны** — на месте отрыва остаётся заглушка: тёмное кольцо «шва»
  с пушком.
- **Пришивание** — деталь в зоне радиуса раны телепортируется на место,
  пружинит, вспыхивают искры; для удобства чипы внизу подсвечивают,
  что оторвано (клик — камера наводится на деталь).
- **Звук** — синтезируется WebAudio на лету: скрип резины живой
  (частота/громкость зависят от текущего натяжения), «хлопок» при отрыве,
  «звон иглы» при пришивании.

## 🛠 Технологии

- **Babylon.js** (CDN, без сборщиков) — рендер, сцена, пикинг, частицы, слои
- **WebAudio API** — процедурный звук
- **Canvas 2D** (через `DynamicTexture`) — процедурные текстуры:
  клетка рубашки, деним, песок, плакат «WANTED», горошек на трусах,
  спрайт частиц, градиент неба
- **Чистый JS** (ES2020), ноль зависимостей в рантайме

Запуск: просто открыть HTML-файл в браузере (или отдать любым статическим
сервером). Для звука нужен первый клик по странице — так браузеры
разрешают `AudioContext`.

### Система конечностей (сердце игры)

Каждая конечность описывается конфигом и оборачивается в `makeLimb()`:

```js
{ root,          // TransformNode-«плечо» (точка крепления)
  tipExtent,     // длина до кончика со знаком (+Y голова / −Y руки-ноги)
  axis,          // ось «роста» для ориентации
  thr,           // порог отрыва (в единицах stretch)
  restQuat,      // поза покоя
  bends,         // [[node, угол]] — локоть/колено выпрямляются при тяге
  pickR/pickPos, // невидимая сфера захвата
  capR }         // размер раны
```

**Автомат конечности** (обновляется каждый кадр в главном цикле):

```
                 ┌──────────────── ПРИКРЕПЛЕНА ────────────────┐
                 │                                              │
   idle ──grab──▶ dragging ──stretch≥thr──▶ tear() ──▶ ОТОРВАНА
   ▲    ◀─пуск──    │  ▲                            fly (физика)
   │      пружина   │  │   grab                        │ отскоки
   │    sVel-осц.   │  └─ к ране < 0.5 ── reattach() ─┘
   └────────────────┴───────────── (сnapT-анимация посадки) ──┘
```

- **Тяга**: курсор проецируется на `dragPlane` — плоскость через точку
  захвата, перпендикулярная камере (`Plane.FromPositionAndNormal`).
  `stretchTarget = dist / reach`, направление — `aimQuat()` (кватернион
  «ось → dir» + коррекция закручивания, чтобы лицо не поворачивалось
  затылком).
- **Пружина**: интегратор `sVel += (target-stretch)·k·dt; sVel *= damp;
  stretch += sVel·dt` — даёт overshoot и «боянг» при отпускании.
  Растяжение — `scaling.y`, утончение по `1/√y` (объём ≈ константен).
- **Отрыв** (`tear`): раскладывает мировую матрицу (position/rotation/
  scaling), отцепляет `root` от тела и **компенсирует позицию так, чтобы
  кончик остался в точке разрыва** — деталь не «телепортируется» к плечу.
  Дальше — свободный полёт с угловой скоростью и коллизией с полом
  (проверяется и «гнездо», и кончик детали).
- **Пришивка** (`reattach`): обратное — возвращает родителя и пересчитывает
  мировую ориентацию в локальную через `Inverse(parentQuat) · worldQuat`,
  запускает snap-анимацию посадки.
- **Бросок**: при переносе детали считается мгновенная скорость;
  на отпускании она становится `fly.v` (с ограничением 7 м/с).

### Система координат захвата

Захваченная точка переводится в **локальные координаты** детали
(`grabOffsetLocal`) — поэтому деталь можно крутить/швырять, держа
за палец, а она сохраняет точку приложения силы. При отрыве
пикинг переходит на сами меши детали.

### Пикинг

- Карта `pickMap: Mesh → limb` — единственный источник истины,
  кто схвачен. Фильтр `scene.pick(..., m=>pickMap.has(m))`.
- Зоны захвата — **невидимые, но пикаемые** сферы: `visibility = 0`
  (не `isVisible = false`, который исключает из пикинга).
- Hover: пере-пик каждые 40 мс + `HighlightLayer` (золотая подсветка),
  до первого рывка — мигающая подсказка «за что хватать».

### Частицы

Одна **общая** текстура-спрайт `flare` (радиальный градиент):
- постоянные системы: пыль, пламя, искры, дым костра;
- одноразовые всплески через `burst()`: `manualEmitCount` +
  `targetStopDuration`, удаление через `dispose(false)` —
  `false` критично, чтобы не убить общую текстуру.

### Звук

Ленивая инициализация `AudioContext` (по первому клику — политика
автоплея браузеров). Скрип — долгоживущий `sawtooth`-осциллятор
через lowpass, параметры которого обновляются **каждый кадр**
от реального натяжения (`creakUpdate`). Одноразовые эффекты —
осцилляторы + буфер белого шума, синтез на лету.

### Главный цикл

`onBeforeRenderObservable`, `dt` зажат 50 мс (устойчивость к лагам).
Порядок: конечности → наклон корпуса к тяге → дыхание → взгляд/моргание →
лагерь → tumbleweed → камера (интро-зум, авто-вращение при простое,
тряска) → подсказки.

### Ключевые технические решения

| Решение | Зачем |
|---|---|
| `rotFromTo()` своя | в Babylon.js нет `RotationFromTo` — пишем через `RotationAxis` (ось = cross, угол = acos) |
| `visibility=0` | невидимая, но пикаемая зона захвата |
| `dispose(false)` | частицы не убивают общую текстуру |
| `TransformNode(имя, scene)` + `.parent` | второй аргумент — ВСЕГДА сцена, не родитель |
| `pi.input`, `pr.pickedMesh` | актуальные поля API, за которыми мы следим |
| VOID-функции `*ToRef` | пишут в переданный объект, ничего не возвращают |

## ✅ Как проверить, что всё живо

1. Открыть файл — сцена рисуется, консоль чистая.
2. Навести на кисть — золотая подсветка, курсор «рука».
3. Потянуть — полоска растёт, слышен скрип (после первого клика).
4. Довести до красного — отрыв: хлопок, тряска, деталь летит.
5. Схватить деталь, поднести к ране — искры, «пришито +1».
6. F12 → Console — пусто на всех этапах.
